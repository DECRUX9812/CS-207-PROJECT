# CS-207 obstacle-avoiding car

Arduino project for a small car that uses an ultrasonic sensor and servo to detect obstacles and choose a direction. The repository contains the Arduino sketch, project write-up, and supporting material.

## Hardware

- Arduino Uno
- Chassis and motors
- Motor shield or H-bridge driver
- Ultrasonic sensor
- Servo motor
- Wires and USB cable

The original project video is [available on YouTube](https://youtu.be/l1GVSmRTWdQ).
